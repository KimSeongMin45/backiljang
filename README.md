# 온라인 백일장

- 고양이

```
고 : 고작 한 번의 다정함으로도 사람은 살아갈 힘을 얻는다는데
양 : 양껏 사랑받고 싶으면서도 상처받을까 봐 도망치는 나는
이 : 이제야 알았다, 고양이가 도망치는 건 사랑이 싫어서가 아니라는 걸.
```

- 강아지

```
강 : 강한 척하던 나도 네 앞에서는 꼬리를 흔들고 싶었다.
아 : 아무 조건 없이 나를 반겨 주는 존재가 세상에 하나쯤 있다면
지 : 지금 내가 돌아가고 싶은 곳은 집이 아니라, 네가 있는 곳이다.
```

- 비둘기

```
비 : 비가 오면 사람들은 우산을 펴고, 비둘기는 처마를 찾는다.
둘 : 둘 다 젖지 않으려 애쓰는데, 누구는 우산을 쓰고 누구는 쫓겨난다.
기 : 기울어진 세상에서도 비는 똑같이 내린다는 걸, 우리는 왜 잊을까.
```
